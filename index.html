Как пользоваться

Выберите категорию и создайте персонажа. У каждого поля есть кнопки «Ещё» и «Закрепить». Редактор позволяет уточнить описание вручную.

Новое поколение карточки сохраняет закреплённые поля. Для смены категории может потребоваться снять несовместимые закрепления.

Редактировать персонажа

При изменении возраста несовместимые описания будут подобраны заново. Ручные правки задают описание по вашему выбору.

Справка мастера

Генератор создаёт обычных жителей мира, а не сюжетные откровения. Осведомлённость относится к теме вашей текущей игры: конкретные факты определяете вы.

Word и резервная копия

«Скачать NPC (.docx)» создаёт документ Word текущего персонажа. «Резервная копия NPC (.json)» сохраняет данные для обратного импорта: это не документ для чтения, и мобильный браузер может показать его как текст.

Экспорт всех NPC в DOCX

Раздел «История» хранит всех персонажей, созданных после этого обновления, даже без нажатия «Сохранить». Экспорт включает всю историю; каждый NPC начинается с новой страницы. Правки и повторная генерация отдельных полей обновляют запись персонажа. При скрытии информации мастера она также исключается из DOCX. Старые несохранённые карточки восстановить невозможно.

Данные и работа без сети

Сохранения остаются в браузере и не отправляются на сервер. Очистка данных сайта удалит библиотеку. Регулярно делайте экспорт JSON.

После сообщения «Готов к работе без сети» приложение можно открывать без интернета. Для обновления закройте все вкладки приложения и откройте его снова с сетью.

Импорт добавляет персонажей и не заменяет существующие записи. При совпадении идентификаторов создаются новые.
