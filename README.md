# Генератор NPC | Glufonde Fracture

Статический инструмент для мастера: обычные жители мира для неожиданной встречи во время игры. Без сервера, внешних API, ИИ и зависимостей во время работы. Русский интерфейс, чёрный фон, приглушённое золото, светлый текст. Разработка относится исключительно к `MAKAKOBHA/NPC-Generator-Glufonde`.

## Возможности

- Четыре категории: мужчина и женщина (18–80), мальчик и девочка (6–17).
- Имя, фамилия нужного рода, возраст, каноническое место рождения, внешность, одежда, голос, речевая и поведенческая привычки, занятие и настроение.
- Пять уровней осведомлённости и три пресета распределения; конкретные сюжетные факты определяет мастер.
- Повторная генерация каждого поля и закрепление отдельных полей при создании следующего NPC.
- Ручное редактирование, копирование, локальная библиотека, поиск, удаление, импорт и экспорт JSON.
- Работа без сети после полного кэширования приложения; никаких CDN и внешних шрифтов.

## Быстрый запуск

Нужен HTTP-сервер: открытие `index.html` через `file://` не поддерживает загрузку JSON и service worker.

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для запуска и генерации установка npm-пакетов не требуется. Service worker работает на HTTPS или localhost.

## Использование

1. Выберите категорию, пресет и нажмите «Сгенерировать».
2. Кнопка «Ещё» обновляет соответствующее поле. «Закрепить» сохраняет его при следующей генерации.
3. Для изменения категории закреплённые поля должны быть совместимы с новым возрастом и полом. Иначе карточка остаётся прежней, а приложение объясняет, какие ограничения мешают генерации. Незакреплённые несовместимые значения подбираются заново.
4. «Редактировать» открывает все поля карточки. При смене возраста несовместимые значения обновляются; явные ручные правки считаются решением мастера. Возраст ограничен категорией, место рождения — каноническим списком.
5. «Сохранить» создаёт отдельную запись. При открытии записи из библиотеки появляется «Обновить сохранённого» с явным подтверждением замены. Повторное сохранение создаёт копию с новым идентификатором.
6. «Скрыть информацию мастера» убирает её из карточки, редактора и копируемого текста. **Экспорт JSON остаётся полным архивом, включая информацию мастера**: не передавайте его игрокам как сокращённое описание.

Копирование использует Clipboard API. Если браузер запрещает его, приложение показывает текст для ручного копирования. Если localStorage заблокирован или заполнен, генерация продолжает работать; текущую карточку можно экспортировать.

Библиотека хранится только на этом устройстве, в этом браузере и для этого адреса сайта. Очистка данных сайта удаляет сохранения. Делайте резервные копии через экспорт. Импорт добавляет записи, не заменяя существующие; совпадающие с библиотекой идентификаторы заменяются новыми. Повторяющиеся ID внутри импортируемого файла, неизвестная версия, недопустимые поля и повреждённый JSON отклоняются целиком. Ограничения: 5 МБ на файл и 2000 записей в библиотеке. Повреждённое локальное хранилище не перезаписывается молча.

Место рождения: ровно 15 перечисленных в задании городов Уморы и три зарубежные страны — Стаб, Королевство Карбанто, Бигла. Зарубежные города не создаются. Каждому городу присвоен вес 6, каждой стране — 3: вероятность города в сумме 90,9%. Веса редактируются в `data/locations.json`.

Внешность состоит из одного описания волос, одной черты лица либо осанки и одной детали одежды. Таким образом, взаимоисключающие варианты волос или телосложения не объединяются. Возрастные ограничения исключают, например, седину у детей. Обычные черты имеют вес 5, редкие — 1. Пол и возраст учитываются при выборе занятий; для нескольких городов действуют мягкие профессиональные предпочтения из задания. Культурные метки имён описывают общие центральноевропейские влияния, а не неподтверждённый канон стран.

## Архитектура и расширение

- `index.html`, `css/style.css` — адаптивный интерфейс и доступные элементы управления.
- `js/config.js` — централизованные настройки и русские подписи.
- `js/random.js` — криптографическая случайность с устранением смещения диапазона; запасной вариант `Math.random`.
- `js/generator.js` — взвешенный выбор, совместимость, закрепления, история 30 последних значений с максимумом 16 попыток.
- `js/storage.js`, `js/validation.js` — версионированная библиотека и проверка данных.
- `js/app.js`, `js/ui.js` — события, формы и безопасное отображение через `textContent`.
- `data/*.json` — игровой контент отдельно от кода.
- `tools/prepare-site.js`, `tools/sw-template.js`, `sw.js` — статический артефакт и офлайн-кэш.

Имена используют `{ "text": "Ян", "culture": "central-european" }`. Фамилии всегда задаются парой `{ "male": "Каминский", "female": "Каминская", "culture": "central-european" }`; автоматического преобразования окончаний нет. Черты используют `text`, `minAge`, `weight`; профессии дополнительно содержат `male`, `female`, `maxAge` и необязательное `affinity` с названием города. Новые записи добавляйте вручную, проверяя содержание и уникальность; затем запускайте тесты.

## Тестирование

Нужен Node.js 22 или новее (проверено на 24).

```sh
npm test
node tests/core.test.js
npm run prepare:site
```

15 тестов охватывают размеры и дубли справочников, формы фамилий, 4000 сгенерированных карточек, возраст, род, канон, ограничения черт, точные весовые интервалы трёх пресетов, отдельную регенерацию, закрепления, смену категорий, сохранение, экспорт/импорт, повреждённые данные и ограниченное предотвращение повторов. В некоторых средах `npm test` отображает один файловый набор; прямой запуск показывает все 15 тестов.

Дополнительный браузерный сценарий: `tests/browser.py`, Python + Playwright и установленный Chromium. Это только инструменты разработки. По умолчанию сценарий ожидает приложение по адресу `http://127.0.0.1:8000/NPC-Generator-Glufonde/`, то есть HTTP-сервер из родительского каталога. При другом расположении измените `URL` в сценарии.

Проверено в Chromium: 320, 375, 390, 768, 1440 px, четыре категории, отсутствие горизонтального переполнения, закрепление и отдельная регенерация, скрытие информации мастера, редактор, библиотека после перезагрузки, обновление с подтверждением, импорт/экспорт, поиск, удаление, неверный JSON, офлайн-перезагрузка и генерация в подпапке. JavaScript-ошибок в этих сценариях не обнаружено. Проверка на физических iPhone, в Safari, Firefox и Telegram не выполнялась.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` проверяет PR и собирает статический артефакт. После слияния в `main` запускается публикация. Все ссылки относительные, серверный роутинг отсутствует, scope service worker соответствует каталогу приложения.

Владельцу репозитория:

1. Проверить и самостоятельно слить Pull Request в `main`.
2. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**.
3. Проверить успешное выполнение workflow «Проверка и публикация GitHub Pages». При необходимости запустить его вручную через Actions → Run workflow.
4. Открыть `https://makakobha.github.io/NPC-Generator-Glufonde/` и дождаться сообщения «Готов к работе без сети».

Публикация из рабочей ветки не выполняется. Наличие workflow само по себе не означает, что сайт опубликован.

Перед каждым выпуском запускайте `npm run prepare:site` и добавляйте обновлённый `sw.js` в коммит. Скрипт вычисляет хэш всех HTML/CSS/JS/JSON, записывает список ресурсов и создаёт `_site/`. Workflow делает это также автоматически. Установка нового кэша атомарна; `skipWaiting` не используется: новая версия ждёт закрытия всех старых вкладок, затем удаляет старые кэши этого приложения. Сохранения localStorage не затрагиваются. Чтобы получить обновление, закройте все вкладки приложения и откройте сайт при доступной сети. Первое кэширование требует сети; недоступный service worker обозначается в подвале.
